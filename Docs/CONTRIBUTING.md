# 문서 작성 및 검토 규칙

- 현재 상태는 Draft / 작성예정입니다. 사용자 수정 요청을 반영한 뒤 실습 본문을 작성합니다.
- 모든 항목은 [루트 한국어 템플릿](../TEMPLATE.md)의 11개 제목을 동일한 순서로 유지합니다.
- 정확한 영문 제목, Node ID 및 매핑 경로를 보존합니다. 신규 항목은 승인 없이 추가하지 않습니다.
- 사전준비, 최소 권한, 비용, 절차, 기대 결과, 문제해결, 정리를 항목별로 작성합니다. 상위 개요를 모든 하위 문서에 복제하지 않습니다.
- Oracle 공식문서 본문을 확인하고 관련 출처를 명시합니다. 현재 링크는 기존 Roadmap 출처이며 최신성이나 접속 성공을 새로 검증했다는 의미가 아닙니다.
- 실제 실행 전후 증거가 없으면 완료 또는 실행 검증됨으로 표시하지 않습니다. 구조 검증과 OCI 실습 검증을 구분합니다.
- 공개 저장소에 고객정보, 실제 OCID/IP/네트워크 경로, 내부 로그, 자격증명 또는 서버 원본 응답을 넣지 않습니다.
- 문서 연결 변경과 roadmap.sh 편집은 별개입니다. 이번 작업은 GitHub만 대상으로 하며 roadmap.sh를 변경하지 않습니다.
